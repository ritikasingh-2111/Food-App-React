# 🍔 Food App React

A responsive Food Ordering App built using React, JavaScript, HTML, and CSS.

## Features

- Responsive design
- Simple and clean UI
- React components
- Easy to use

## Technologies Used

- React
- JavaScript
- HTML
- CSS

## How to Run

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the project:
   ```bash
   npm start
   ```
